# LED-Badge
A super simple badge shaped board with 5 LEDs on it, it would show how you are feeling, one LED on being bad and all 5 being good!

# Hour 1 — Learning the Basics...

I used something called EasyEDA to start learning the basics of PCB design. It was pretty difficult to start but once I learned a few simple hotkeys and places to find parts, it turned out to be pretty okay! I chose a very simple project to start off, which is just an LED badge that shows your mood on a rating from 1-5:

It was fairly easy to wire it up! I loved this bit the most :D

After looking at the connections that AutoRoute made (I forgot to mention it, I clicked on it and didn't realize anything changed, I guess), I realized how messed up it looked, and I guess during Hour 1 and 2, I was so fixated on making it look pretty I forgot that it actually needs to work XD
